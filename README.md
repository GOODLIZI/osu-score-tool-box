# osu! 游玩成绩获取工具

一个本地 Windows 桌面工具，通过 osu! API v2 绑定多个个人账号，查看玩家信息，并把「最近游玩 / 最佳成绩」按指定格式复制到剪贴板。

## 功能

- **OAuth 授权绑定账号**：每个账号在浏览器里登录 osu! 授权一次即可绑定，支持多个账号。
- **玩家信息展示**：头像、用户 ID、PP、等级（含进度）、ACC（准度）、地区、地区排名、全球排名、总游玩次数与总游玩时长。
- **模式切换**：osu! / osu! taiko / osu! catch / osu! mania 四种模式分开显示，互不混合。各模式的玩家数据（PP、等级、ACC、地区/全球排名、游玩次数与时长）相互独立，切换模式会立即刷新；玩家的**主模式**会在模式选择处标注「（主模式）」。
- **最近游玩**：把所选模式下按「成绩获取设置」的最近数量复制到剪贴板（默认 1 条）。
- **最佳成绩**：把所选模式下按「成绩获取设置」的最佳数量复制到剪贴板（默认 10 条，多于 1 条时带序号）。
- **lazer / stable 兼容**：同时兼容 osu!stable 与 osu!lazer 两种来源的成绩，成绩文本中会标注游戏版本。
- **显示设置**：按模式分别自定义输出的列与顺序、谱面状态、谱面编号、谱师、miss 数，以及 ACC / PP 的显示方式。
- **默认模式**：在「显示设置」里选择默认模式，下次启动程序会自动进入该模式。
- **获取与输出设置**：按模式分别设置最近 / 最佳成绩的默认获取数量（1~100），选择「成绩默认输出方式」（剪贴板 / txt 文件），设置「成绩信息 txt」与「背景图片」两个保存位置，并可勾选「统一位置」让所有文件保存到同一路径。
- **成绩输出到 txt**：默认输出方式选 txt 后，按钮与 `/r`、`/bp` 会把成绩写入 txt（内容与剪贴板一致）；指令生成的文件名带模式段（如 `Bestplay mania 1-20 2026-09-30 14-05.txt`），主界面按钮的文件名不带模式段（如 `Bestplay 1-20 2026-09-30 14-05.txt`）；也可在指令末尾用 `-copy` / `-txt` 临时切换。
- **谱面背景图**：用 `/bg` 指令，或点主界面「更多功能 → 获取谱面背景图」，按谱面编号下载背景原图（full）或裁剪缩略图（cover）。
- **成绩指令**：在「指令」输入框输入 `/r`、`/bp`、`/bg`、`/show`、`/user`、`/s` 等指令，获取成绩、下载背景图或查询任意玩家。
- **更多功能**：主界面「更多功能」菜单提供「用户查询功能」（按名字/ID 查看玩家信息、查找、下载头像、输出资料）、「获取谱面背景图」与「指定谱面成绩获取」（按谱面编号查最佳 pp/acc/分数）。

## 成绩文本格式

单条格式用 ` | ` 分隔，默认列顺序如下（列可自定义，见下文「显示设置」）：

```
歌曲名 | 模式 | 游玩平台 | 难度名 | ★星数 | 模组 | 分数 | 准度% | PP | 详细判定
```

> 「游玩平台」由选项「单独显示游玩平台」控制：勾选时为独立一栏（上方顺序），不勾选时合并进「模式」栏（如 `osu! (lazer)`）。

示例（最佳成绩带序号）：

```
1. (Ranked) Blue Zenith | osu! | stable | Extra (4965337) by Asphyxia | 6.78★ | HD | 1234567 | 98.50% | 301pp | 3.2:1 FC
2. ...
```

### 显示设置

点击顶部 **显示设置** 打开弹窗，可**按模式分别**配置（osu! / taiko / catch / mania 各存一套，保存在 `config.json`）：

- **默认模式**：弹窗顶部的「默认模式」决定**启动程序时默认进入的模式**（同时也是下方设置所对应的模式）。
- **单独显示游玩平台（stable/lazer）**：勾选时「模式」与「游玩平台」分成两栏（`osu! | lazer`）；不勾选时合并为一栏（`osu! (lazer)`）。
- **显示哪些列、列的顺序**：勾选要输出的列，用 ↑↓ 调整顺序；**曲名固定显示且恒在第一位**。某列被关闭或内容为空时整列省略（不会留下多余分隔符）。
- **在曲名前显示谱面状态**：显示为 `(Ranked) 曲名`，状态取自 `beatmapset.status`（Ranked / Approved / Qualified / Loved / Pending / WIP / Graveyard）。
- **在难度名后显示谱面编号**：谱面编号为谱面难度 ID（`beatmap.id`），即 `https://osu.ppy.sh/beatmapsets/<谱面集>#<模式>/<编号>` 中网址最后的数字，可在 osu! 网站按编号直接打开对应难度。
- **在难度名后显示谱师**：显示为 `难度名 (编号) by 谱师`，谱师取自 `beatmapset.creator`（地图集作者；客栈难度的作者可能与地图集作者不同，此栏显示地图集作者）。
- **在详细判定中显示 miss 数**：无 miss 显示 `FC`，有 miss 显示如 `1miss`。
- **ACC 显示方式**：默认（两位小数 + `%`，如 `96.17%`）、省略百分号（`96.17`）、四位数（`96.17%` → `9617`，不补前导零）；数值按 osu! 规则**向下取整**到两位小数。
- **PP 显示方式**：默认（四舍五入到整数，如 `155pp`）、精确（保留两位小数，如 `154.75pp`）。
- **星数显示方式**：默认（`4.76★`）、星号显示（`4.76*`）、省略★（`4.76`）；星数同样按 osu! 规则**向下取整**到两位小数。

弹窗内的**预览**会实时显示当前设置的输出效果；`恢复本模式默认` 可把当前模式恢复为默认设置。

### 各列说明

- **曲名**：默认显示歌名；开启「在曲名前显示谱面状态」后显示为 `(Ranked) 曲名`。
- **模式 / 游玩平台**：`模式` 为游玩规则（osu! / taiko / catch / mania），平台为游戏版本（`lazer` / `stable`）。
  - 勾选「单独显示游玩平台」时输出 `osu! | lazer`（两栏）；不勾选时输出 `osu! (lazer)`（一栏）。平台不再是可排序字段，始终紧跟「模式」。
  - 平台判定依据：osu! API v2 中，lazer 成绩为 Solo Score（`best_id` 为 `null`，不进入旧版排行榜），stable 成绩为 Legacy Score（`best_id` 为对应排行榜成绩 ID）。
- **难度名**：默认显示难度名；开启「在难度名后显示谱面编号」会追加 ` (编号)`，开启「在难度名后显示谱师」会再追加 ` by 谱师`（如 `[4K] difficulty (1111111) by charter`）。
- **星数**：默认为基础星数；当成绩使用 DT / NC / HT / HR / EZ 等会改变星数的模组时，程序会通过 osu! API 的谱面属性接口（`POST /beatmaps/{id}/attributes`）按实际模组计算星数（例如 DT 星数升高、HT 星数降低）。若成绩使用了**自定义倍速**的 DT / HT（lazer），接口无法计算其星数，此时回退显示基础星数。
- 无模组显示 `NM`；多个模组用 `+` 连接（如 `NF+HD`）；自定义倍速的 DT/HT 会附带倍速（如 `1.2DT`、`0.95HT`）。
- PP 为空（如未进榜谱面）显示 `N/A`。
- **详细判定** = 彩黄比 + miss 数（用空格分隔；miss 可在显示设置中关闭）。
  - 彩黄比 = 最高准度判定 ÷ 第二高准度判定，归一为 `X:1`（第二高恒为 1）：
    - osu!mania：MAX(320) ÷ 300 → `perfect : great`（旧键名 `count_geki : count_300`）
    - osu! / osu!taiko：300 ÷ 100 → `great : ok`（旧键名 `count_300 : count_100`）
    - osu!catch：300 ÷ 100 → `great : large_tick_hit`（旧键名 `count_300 : count_100`）
    - 当前 API 的 `statistics` 使用现代键名，程序同时兼容新旧两种键名。
    - 例如 MAX 900、300 100 显示 `9:1`；第二高为 0 且最高 >0 显示 `∞:1`。
  - miss 数：无 miss 显示 `FC`，有 miss 显示如 `1miss`。
  - 当 300 判定（`great` / `count_300`）个数为 0 时，不显示彩黄比，仅显示 `FC` 或 miss 数（如 `FC`、`2miss`）。


## 获取与输出设置与指令

### 获取与输出设置

点击顶部 **获取与输出设置**，可以：

- **成绩获取数量**：按模式分别设置「最近成绩数量」「最佳成绩数量」（范围 1~100，默认最近 1 条、最佳 10 条）。「最近游玩」「最佳成绩」按钮会按对应模式的设置直接获取（不再弹窗询问）；结果多于 1 条时自动加 `1. 2. 3.` 序号，取不满时状态栏提示「请求 X 条，实际 Y 条」。
- **成绩默认输出方式**：`输出至剪贴板`（默认）或 `输出至 txt 文件`。按钮与 `/r`、`/bp` 都遵循该设置；指令末尾可用 `-copy` / `-txt` 覆盖本次输出。
- **保存位置**：分「成绩信息 txt」与「背景图片」两栏，可点「选择文件夹…」或直接输入路径（保存时会转为绝对路径）；也可勾选「统一位置」，填写一个统一路径，此时背景图与成绩 txt（及头像）都保存到该路径，原两栏会变灰但仍保留原内容。

> 输出 txt 需要先设置「成绩信息 txt」保存位置，获取背景图需要先设置「背景图片」保存位置：未设置时会提示（如「请设置成绩保存路径后获取成绩」）并直接打开本设置界面；路径不存在时会报错。

### 成绩指令

在界面下方的「指令」输入框输入指令并按回车（或点「执行」）即可执行。`/r`、`/bp` 作用于**当前选中的模式**，也可在末尾加模式后缀 `(osu)` / `(taiko)` / `(catch)` / `(mania)` 指定其它模式；`/bg` 按谱面编号下载背景图；`/show`、`/user` 按名字/ID 查询任意玩家（详见 `指令说明.md`）：

| 指令 | 含义 |
| --- | --- |
| `/r` | 最近 1 个成绩 |
| `/r a` | 最近的 a 个成绩 |
| `/r a b` | 最近第 a 到第 b 个成绩 |
| `/bp` | 单曲 pp 最高的 1 个成绩 |
| `/bp a` | 单曲 pp 最高的 a 个成绩 |
| `/bp a b` | 第 a 高到第 b 高的成绩 |
| `/bg full 谱面编号` | 下载该谱面的背景原图（fullsize） |
| `/bg cover 谱面编号` | 下载该谱面的裁剪缩略图（cover） |
| `/r <形式> [(osu|taiko|catch|mania)] [-copy|-txt]` | 末尾可加模式后缀与输出方式后缀，各最多一个 |
| `/bp <形式> [(osu|taiko|catch|mania)] [-copy|-txt]` | 末尾可加模式后缀与输出方式后缀，各最多一个 |
| `/show name 玩家名` | 以弹窗显示指定玩家名的玩家信息 |
| `/show id 玩家ID` | 以弹窗显示指定ID的玩家信息 |
| `/user find name 玩家名` | 通过玩家名查找ID（弹窗+剪贴板） |
| `/user find id 玩家ID` | 通过ID查找玩家名（弹窗+剪贴板） |
| `/user avatar name|id 玩家名/玩家ID` | 下载玩家头像到图片保存路径 |
| `/user profile name|id 玩家名/玩家ID [-copy|-txt]` | 输出玩家信息到剪贴板/txt |
| `/s pp 谱面编号` | 获取你在该谱面的最佳 pp 成绩（复制到剪贴板） |
| `/s acc 谱面编号` | 获取你在该谱面的最佳 acc 成绩（复制到剪贴板） |
| `/s score 谱面编号` | 获取你在该谱面的最佳分数成绩（复制到剪贴板） |

通用规则：

- 参数必须是正整数（≥ 1）；两个参数时必须 `a < b`；一次最多获取 100 条。
- `/bg` 需要先在「获取与输出设置」里设置图片保存位置；保存的文件名为 `<谱面编号> <种类>.jpg`。
- `/r`、`/bp` 默认按「成绩默认输出方式」输出，可在末尾用 `-copy` / `-txt` 覆盖本次输出方式。
- `/r`、`/bp` 可加模式后缀 `(osu)` `(taiko)` `(catch)` `(mania)` 指定取数模式（不加则用主界面当前模式）；模式后缀与输出方式后缀各最多一个、顺序不限，例如 `/r 2 6 (mania) -copy`。
- 输出 txt 时，指令生成的文件名为「前缀（Bestplay / Recent）+ 模式 + 区间 + 时间」，如 `Bestplay mania 1-20 2026-09-30 14-05.txt`、`Recent mania 3-5 2026-09-30 14-05.txt`；主界面按钮生成的文件名不带模式段（如 `Bestplay 1-20 2026-09-30 14-05.txt`），内容与剪贴板一致。
- `/user profile` 输出到 txt 时文件名为 `<玩家名> profile <模式> <时间>.txt`；`/user avatar` 下载头像为 `<玩家名> avatar.png`（已存在同名文件会停止并报错）。
- `/s pp|acc|score 谱面编号` 获取该谱面最佳成绩，仅复制到剪贴板（不支持 `-copy`/`-txt`）；只对有排行榜的谱面有效。
- 同一分钟内在同一保存位置生成同名 txt 会提示「获取间隔过短」（换保存位置或稍后再试）。
- 指令名大小写不敏感；未知指令或参数错误会弹窗提示。
- 点「指令帮助」可查看当前支持的全部指令（列表由程序内的指令注册表自动生成，增删指令后会自动更新）。
- 完整的指令说明见工作目录下的 **`指令说明.md`**。未来新增指令的使用方式将直接填入指令说明.md中。
- **最近成绩受 osu! API 限制：只包含最近 24 小时内的成绩，且最多取到第 100 个**；最佳成绩不受此限制。

## 使用前提：注册 osu! OAuth 应用（只需一次）

1. 登录 [osu! 官网](https://osu.ppy.sh/)，进入 **账号设置 → OAuth**（https://osu.ppy.sh/home/account/edit#oauth）。
2. 点击 **Register new application**。
3. **Application Name** 随意填写（如 `osu-scores-tool`）。
4. **Application Callback URL** 必须填写：`http://127.0.0.1:5050/callback`（必须与程序中的回调地址完全一致）。
5. 保存后记录页面上显示的 **Client ID** 和 **Client Secret**（Secret 相当于密码，不要泄露给他人）。

## 运行

双击 `run.bat` 即可（脚本会自动使用本机 Python；若未安装 Python，请先安装 Python 3.10+）。

首次使用：

1. 点击 **API设置**，填入 Client ID、Client Secret、回调地址（默认已填好）。
2. 点击 **绑定账号**，浏览器会打开 osu! 授权页——登录你要绑定的账号并点击授权。
3. 授权完成后自动回到程序，账号即绑定成功。重复此步骤可绑定多个账号。

之后每次启动，程序会进入「显示设置」里选定的**默认模式**（可在顶部切换模式查看其它模式）：从顶部下拉框选择账号即可查看数据；点 **最近游玩 / 最佳成绩** 会自动复制到剪贴板，或用下方「指令」输入框按范围取成绩（见「成绩获取设置与指令」）。

## 配置文件

- `config.json`（运行时自动生成）：保存 API 凭证、各账号的访问令牌，以及显示设置、获取与输出设置（含成绩/图片保存位置、统一位置与成绩默认输出方式）、默认模式。**令牌是敏感信息，请勿把该文件分享给他人。**
- 想换绑/清空：可在程序里「删除账号」，或在无账号状态下删除 `config.json`。

## 注意事项

- 请遵守 osu! API 使用条款：不要高频轮询，官方建议不超过 60 次/分钟。本工具只在手动操作时请求。
- 计算带模组星数会额外调用谱面属性接口；同一「谱面 + 模组」组合在本次会话内只请求一次（最近游玩 1 条最多 1 次，最佳成绩按含 DT/NC/HT/HR/EZ 的成绩数计算）。
- 回调端口（默认 5050）如需修改，必须同时修改 osu! 侧注册的回调地址和 `config.json` 里的 `redirect_uri`。
